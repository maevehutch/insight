Vis 1 explanation & rationale:
With the line chart above I have attempted to create an interactively driven visualisation showing the population change of every country over a 4 century period, however I was unable to implement the visualisation exactly as I had intended. The legend on the right hand side is interactive and allows for the selection of one or more countries for comparison (holding shift), unfortunately not all of the countries are visible since I was not able to implement this. My intention was for the legend to either be extended to show all countries or have a scrolling and search bar functionality to find countries easily. Another feature I was unable to implement was the scaling of the Y axis values depending on which countries are selected. For example, selecting 2 countries with low populations (<10,000,000) would make it very hard to compare them as their values are crammed into the bottom of the chart. My intention was to scale the Y axis appropriately so that its highest value was correlated to the population levels of the countries selected, allowing for the user to clearly see the population difference and changes between selected countries. I was able to create something similar to this in the example below, but it was using a logarithmic scale which changes the angle and steepness of the curves in the line chart, which is not something I want.
